# Figure attribution

`rod_dimensions.png` derives from experimental image L2-3-B.png in the [PSDI dataset](https://data-collections.psdi.ac.uk/records/sgvf0-j3g53), version 2, by Andrew Stewart and Natalia Da Silva De Sa, licensed CC BY 4.0. It adds a segmentation outline, maximum-Feret segment, moment-ellipse axes, labels and a pixel-coordinate crop. It is an explanatory derivative, not a raw microscope image or independent human review.

Reproduce it by running the frozen rod configuration followed by `measure_rods.py`. See DATA_LICENSES.md and data/holdout_tem/README.md for source and extraction details.
