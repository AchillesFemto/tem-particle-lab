# Changelog

## 0.2.0 - 2026-10-13

Add annotation-free user TIFF analysis with an interactive file chooser, page/channel selection, native-intensity thresholds, crop, dark/bright contrast, optional calibration, connected/watershed previews, CSV/HTML export and versioned particle review. Add compressed-TIFF decoding and eight known-answer input/workflow checks. Keep user data and review outputs local.

## 0.1.0 - 2026-10-13

Initial public project: incremental microscopy Python lessons; configurable TEM segmentation and validation; rod peak grouping; maximum Feret and moment-ellipse measurements; versioned particle review; exploratory spatial/Fourier analysis and one-template dynamics; portable run selection, reports and numerical checks.
