# Rod revision holdout

L2-2-D.png and manual particle polygons from the experimental validation images in the [PSDI dataset](https://data-collections.psdi.ac.uk/records/sgvf0-j3g53), version 2, Andrew Stewart and Natalia Da Silva De Sa. Licensed CC BY 4.0. This is an experimental TEM image, not a synthetic image.

Selected by filename and downloaded only after validation_protocol_rods_v2.json was frozen. Retrieved as a ZIP byte range, decompressed and checked against the archive CRC and file size. Manual polygons were selected by image ID from the dataset annotation file. No physical calibration has been verified. Same-dataset field; independent specimens are not established.
